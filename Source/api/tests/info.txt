Aqui en esta carpeta para que funcione, nombramos cada archivo .py al inicio con test

por ejemplo, si el nombre es ensure_admin, el archivo se llamara, test_ensure_admin, luego podemos ejecutarlo con pytest

para ejecutarlo con pytest, debemos importar pytest, y tambien llamar a la función que queremos probar en este caso de ejemplo, ensure_admin()


import pytest

luego, una ves tenemos la funcion, creada que debe llamarse con test al inicio igual

ejemplo:
